# ResellNom Domain Platform

Multi-registrar domain platform foundation for Admin, Reseller, Sub-Reseller and Client workflows.

Planned adapters: Wix, Namecheap and additional registrars.

Core domains lifecycle: registration, transfer, renewal, restore, DNS, nameservers and EPP/Auth workflows.

WHMCS integration will use a unified API so resellers do not depend directly on individual registrar APIs.
